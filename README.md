# MailCleaner

MailCleaner is a professional Python application that safely analyzes Gmail mailboxes and recommends cleanup actions while protecting important emails.

---

## Features

Current Version: **v0.2.0**

### Completed

- Gmail Authentication
- Gmail Connection
- SQLite Database
- Centralized Configuration
- Logging Framework

### Upcoming

- Metadata Synchronization
- Sender Analysis
- Mailbox Health Report
- Rule Engine
- Cleanup Recommendations
- Archive/Delete Preview

---

## Technology

- Python 3.13
- Gmail API
- SQLite
- PyCharm
- macOS
